## About VoxsAgents

**VoxsAgents** builds AI-powered voice agents, virtual receptionists, appointment booking systems, and communication automation tools for service businesses. We also develop useful open-source software for creators and developers.

Our goal is to help businesses stay available around the clock, respond to customers faster, qualify leads, and turn conversations into actions.

## What We Build

| Solution | What it does |
| --- | --- |
| **AI Voice Agents & AI Receptionists** | Handle inbound calls, answer common questions, capture customer information, and route calls to people when needed. |
| **AI Appointment Booking** | Support booking, rescheduling, cancellations, reminders, and calendar-connected workflows. |
| **Lead Qualification & Follow-up** | Collect lead details and help recover missed opportunities. |
| **Outbound Calling Automation** | Support follow-ups, reminders, and outreach workflows. |
| **SMS & WhatsApp Automation** | Connect customer communication across supported messaging providers. |
| **Website Chat & Voice Agents** | Let website visitors interact with AI through chat and voice. |
| **Analytics & ROI** | Review call activity, outcomes, usage, and revenue-related insights. |

## Open-Source Projects

### 🎬 Open Media Workbench

**Open Media Workbench** is a free, open-source, offline-first desktop media toolkit under active development, with a focus on video editing, media repair, subtitle workflows, transcription, localization, and dubbing.

- **Local-first workflow:** Keep supported media operations on your own computer.
- **Video and audio tools:** Edit and process media using desktop workflows.
- **Localization Studio:** Work with subtitles, transcription, translation, and voice workflows.
- **Open development:** Follow progress, report issues, and contribute on GitHub.

**[Explore Open Media Workbench →](https://github.com/osmangonirabbi13/Open-Media-Workbench)**

> Features, offline AI capabilities, and supported operating systems depend on the release. See the project repository for the current status.
